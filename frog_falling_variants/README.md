# 《俚雨》雙視角青蛙下墜｜第一階段：六個關鍵姿勢

本次刻意停在關鍵姿勢確認階段，**尚未製作 24 格補間、正式 Sprite Sheet、GIF 或下墜模擬**。確認後再進入第二階段，不把六個姿勢的跳格審閱當成完成動畫。

## 素材來源與處理

- 動畫 A：`../參考圖/黑色青蛙躍動剪影.png`，1254×1254，RGBA。
- 動畫 B：`../參考圖/幾何感黑色青蛙剪影.png`，1278×1230，RGBA。

兩張指定素材均已在工作區找到；沒有使用舊的 `Pic/角色定稿/青蛙.png` 替代。原始檔不移動、不覆蓋。各自的 `source_analysis.json` 記錄 Alpha、原圖 SHA256 與輪廓資訊。兩張皆為單一連通輪廓、沒有內部孔洞；各圖既有腳趾照原樣保留。

少量可見原始像素的 RGB 並非精確 #000000（A 最大 [12,12,6]，B 最大 [13,13,13]）。輸出統一 RGB 為 #000000，輪廓與抗鋸齒透明度直接取樣原始 Alpha。沒有生成式重繪、補畫肢體或建立新視角。

## 快速審閱

直接開啟 `compare_preview.html`，不需要網路或伺服器。左右並排查看 A/B；可以暫停、按左右鍵按鈕、拖曳姿勢滑桿，或點選六張縮圖。白底及棋盤只顯示在介面，輸出 PNG 都是真透明。播放功能是**依序切換六個姿勢**，尚未代表正式補間的速度或流暢度。

各視角的 `pose_comparison.png` 為有標記灰底對照圖；`keypose_sheet.png` 為 1536×1024、3×2 的透明六格圖，無文字；`keyposes/pose_A.png` 至 `pose_F.png` 各為 512×512 RGBA。

## 控制點與姿態編輯

雙擊 `launch_editor.bat`，或在專案根目錄執行：

```powershell
py -m pip install -r frog_falling_variants/requirements.txt
py frog_falling_variants/generate.py --editor
```

若 Windows Store 的 Python 別名無法啟動，可使用已安裝的直達路徑：

```powershell
& "$env:LOCALAPPDATA\Python\bin\python.exe" frog_falling_variants/generate.py --editor
```

1. 選擇 A 或 B，再選擇 Pose A–F；左右預覽仍顯示兩個視角。
2. 拖曳原圖上的 root（根部）、joint（關節）、tip（末端）與黃色身體中心；座標存為原圖像素。
3. 選擇 1–4 肢體編號，調整此姿勢的根部角度、彎折角度與張開量。張開量透過既有關節的微小角度實現，沒有拉長骨段。
4. 可調整身體傾斜、整體旋轉、重心 X/Y 小幅偏移，以及四種動作倍率。顯示進階區域後可拖曳黃色主體保護區、橘色選定肢體影響區頂點。
5. 按「重新產生並儲存此視角」，只更新該視角的六個姿勢、對照圖、骨架及姿態 JSON。完成後重新整理 HTML 審閱頁。

預設關節依可見輪廓人工標記，純黑區域內的接合位置仍需設計者確認。不要把控制點拉到其他肢體或改變身體輪廓。Pose A 的預設角度、偏移與張開量都為零，保留原始姿勢；請保持這個基準。介面不會在每次滑動時反覆運算，需按更新按鈕套用；播放速度只改變審閱切換節奏。

## 動作設定與後續補間

每個視角有獨立 `skeleton.json` 和 `keyposes.json`。六個姿勢依序為原始姿勢、開始失衡、最大張開、回轉收回、反向偏移、收束回初始。A 採較明顯、不同步的肢體反應與約 +9°/−5° 的總傾斜；B 約 −6°/+5°，姿態變化較小、審閱速度預設較慢。實際循環節奏仍待第二階段補間後確認。

每個姿勢包含非均勻時間位置、身體角度、整體旋轉、重心偏移、各肢體根部與關節角度、張開程度，以及供第二階段使用的左右肢體延遲。延遲欄位目前只儲存，不作用於六張靜態姿勢。第二階段將使用週期平滑關鍵姿勢插值，並在套用延遲時校正基準以保留初始姿勢；不是單一正弦函數震動。

已保留 duration_seconds=2、fps=12 與支援 16/24 FPS 的設定。正式 FPS 切換、任意影格檢查、PNG 序列、Sprite Sheet、GIF、以及白底加速下墜模擬皆留待你確認姿勢後實作。所有正式影格維持大致置中；重力、世界座標、碰撞與落地停止留給網頁。

## 沿用現有程式

原工具的 `Animator.frame()` 三角網格反向取樣、2 倍超採樣與網格反轉檢查已保留至本資料夾的 `mesh_renderer.py`。`VariantAnimator` 另行提供每視角的影響區、身體保護區及關鍵姿勢角度，沒有重寫原圖取樣器。本工具可獨立運作，舊版工具資料夾已移除。

肢體影響區經平滑衰減，主體保護區權重嚴格為零，頭與身體只有整體剛性旋轉和平移。每張圖片都直接取樣原圖 Alpha，沒有累積變形。關節附近仍有保守的過渡形變，不是獨立分層的精確剛體關節；若某姿勢不符合原設計，應減少幅度或校正骨架，不補畫新結構。

## 重新輸出與檢查

```powershell
py frog_falling_variants/generate.py
py frog_falling_variants/generate.py --variant A
py frog_falling_variants/verify_stage1.py
py frog_falling_variants/smoke_editor.py
```

`generate.py` 目前只輸出六張關鍵姿勢，沒有正式動畫產生指令。`setup_designs.py` 僅供初始化缺少的設計 JSON，不會覆寫既有設定。`inspect_sources.py` 可重新產生原圖檢查資料。

`validation.json` 與驗證腳本檢查來源雜湊、純黑 RGBA、透明邊界、完整留白、原圖連通區與孔洞數、三角形無反轉、四肢動作獨立於整體旋轉、以及沒有提前產生正式動畫。這些檢查不能取代你對造型與動作的確認。未修改互動網頁、雨傘偵測或碰撞系統。
